# 模板占位符契约

生成器（`scripts/generate.mjs`）读取模板并将 `{{PLACEHOLDER}}` 替换为数据生成的 HTML。

## 通用
| 占位符 | 说明 |
|---|---|
| `{{SEO_TITLE}}` `{{SEO_DESCRIPTION}}` `{{SEO_KEYWORDS}}` `{{CANONICAL}}` | 页面 Meta |
| `{{OG_TITLE}}` `{{OG_DESCRIPTION}}` `{{OG_URL}}` | Open Graph |
| `{{SCHEMA}}` | JSON-LD（一个或多个 `<script>`） |
| `{{HEADER}}` `{{FOOTER}}` | 页头/页脚 partial（生成器会设置当前导航高亮） |
| `{{BREADCRUMB}}` | 面包屑 HTML |
| `{{DETAIL_CTA}}` | 详情页分销商 CTA partial |

## 页面占位符
- `home.html`：`HERO_TITLE HERO_SUBTITLE HERO_ACTIONS HERO_TRUST HERO_ART ADVANTAGES CATEGORIES SOLUTIONS ARTICLES NEWS FAQ CTA_TITLE CTA_DESC CTA_ACTIONS`
- `products-list.html`：`PAGE_TITLE PAGE_DESC CATEGORY_CARDS FAQ`
- `product-category.html`：`PAGE_TITLE CATEGORY_DESC GUIDE_LINK TABLE FAE_REVIEW APPLICATIONS ADVANTAGES ALTERNATIVES COMPANIONS FAQ CATEGORY_CTA SIDEBAR`
- `product-detail.html`：`MODEL MODEL_IMAGE MODEL_META MODEL_SHORT MODEL_ACTIONS TAB_OVERVIEW TAB_SPECS TAB_CIRCUIT TAB_DOCS APPLICATIONS ALTERNATIVES COMPANIONS FAQ COMPANION_CARDS DETAIL_SIDEBAR`
- `solutions-list.html`：`PAGE_TITLE PAGE_DESC SOLUTION_CARDS FAQ`
- `solution-detail.html`：`SOLUTION_TITLE SOLUTION_SUMMARY OVERVIEW BLOCK_DIAGRAM ADVANTAGES TECH_STRENGTH BOM_TABLE SCENARIOS INTEGRATION FAQ DETAIL_SIDEBAR`
- `support-list.html`：`PAGE_TITLE PAGE_DESC TAB_BUTTONS TAB_PANELS TAGS FAQ`
- `support-detail.html`：`CATEGORY_LABEL ARTICLE_TITLE AUTHOR_BAR ARTICLE_CONTENT TAGS FAQ RELATED SIDEBAR_TOC`
- `support-category.html`：`PAGE_TITLE PAGE_DESC ARTICLE_CARDS FAQ`
- `news-list.html`：`PAGE_TITLE PAGE_DESC COMPANY_NEWS INDUSTRY_NEWS`
- `news-category.html`：`PAGE_TITLE PAGE_DESC ARTICLE_CARDS`
- `news-detail.html`：`ARTICLE_TITLE DATE CATEGORY_LABEL ARTICLE_CONTENT SHARE RELATED SIDEBAR_NEWS`
- `about.html`：`PAGE_TITLE PAGE_DESC INTRO TEAM_DESC TEAM_STATS TIMELINE CUSTOMS ADVANTAGES CASES FAQ`
- `contact.html`：`PAGE_TITLE PAGE_DESC OFFICES CONTACT_IMAGE FORM QQ`
- `author.html`：`AUTHOR_NAME AUTHOR_CARD AUTHOR_BIO AUTHOR_ARTICLES`
- `tag.html`：`TAG_NAME TAG_DESC TAG_ARTICLES RELATED_TAGS`
